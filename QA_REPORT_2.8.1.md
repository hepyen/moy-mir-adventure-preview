# Проверка «Мой Мир» 2.8.1 · 7 ноября 2026

Объект: отдельная семейная Android-сборка `com.moymir.adventure`. Рабочий оригинал 1.13.5 не изменялся.

## Исправлено

1. Второй мир ранее переключался только в интерфейсе. Сейчас ребёнок вызывает защищённый серверный `advance_my_world`, состояние сохраняется в исходной базе, а родитель видит актуальное состояние.
2. В заданиях ребёнку показывались элементы без назначенного исполнителя, которые сервер не разрешал выполнять. Теперь отображаются только действительно назначенные задания.
3. Для нескольких отправок одного задания в один день порядок статусов мог быть неправильным. История отсортирована по `submitted_at`, актуальный статус берётся из последней попытки.
4. Возвращено родительское управление ежедневными задачами: создание с выбором дней недели, количеством баллов и значком, включение и выключение без удаления истории.
5. Без WebGL движок Three.js вызывал ошибку, после чего экран становился пустым. Реализован резервный 2D-режим с работающим Миро и остальными вкладками.
6. Подписка на события Firebase теперь завершается до регистрации токена, поэтому быстрый callback не должен теряться. При выходе удаляется токен текущего аккаунта, чтобы устройство не продолжало получать уведомления предыдущего пользователя.
7. Устранён риск отображения устаревших семейных данных при смене учётной записи: старые запросы игнорируются по идентификатору пользователя и порядковому номеру обновления.
8. Подписи нижней навигации увеличены для телефонов.

## Проверки

- TypeScript `tsc --noEmit` и production Vite build: успешно.
- Сценарии с имитацией сервера и **синтетическими** аккаунтами ребёнка и родителя (никаких изменений реальной базы): вход, баланс, задачи, отправка выполнения, переход второго мира, награды, духовный рост, семейный чат, родительский редактор, дисциплина. Все проверки пройдены.
- Без WebGL: 320, 360, 390, 430, 768 px; нет ошибок JavaScript и горизонтального переполнения. Миро открывает интерактивный чат.
- Проверены параметры Android-манифеста, сборка Gradle, подпись APK и метаданные версии.
- Серверная очередь уведомлений: на момент проверки ноль необработанных уведомлений и ноль записей об ошибках; это **не подтверждает** доставку на конкретный физический телефон.

## Ограничения и дальнейшие проверки

- Реальное получение push на телефоне, когда приложение закрыто, проверить удалённо невозможно. Требуется тестовая кнопка на устройстве.
- Android OTA через Capgo и откат после неудачной установки необходимо проверить на настоящем телефоне. Проверка наличия ZIP и манифеста не равна проверке применения обновления.
- Сервис Миро использует сторонний бесплатный inference, который может менять лимиты и периодически отказывать.
- В родительском режиме при нескольких детских аккаунтах сейчас автоматически выбирается первый; отдельный переключатель ребёнка пока не реализован.
- Данные из семейной базы обновляются с интервалом и при переходе в приложение; при нестабильном интернете задержки возможны.
- Покрытие автоматизированными тестами частичное: не выполнялись реальные платежи, авторизация на телефоне, аппаратные push, проверка энергопотребления и многочасовое тестирование.

## Повторный запуск тестов

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5248
# В другом терминале:
npm run qa:family
```

Строки с поддельными пользователями и заданиями используются только в изолированных тестах браузера; не отправляются в настоящий семейный Supabase.
