# Мой Мир 2.8 — семейное приложение

Отдельное Android-приложение, которое использует существующий семейный аккаунт и прежние баллы, миры, награды и духовные достижения. Оригинальное рабочее приложение не изменено.

В версии 2.8: главный экран с круглой иконкой Миро EV, именем ребёнка, звёздами и балансом; сохранены два мира с постепенным строительством, исходный летающий Миро и настоящий онлайн-ИИ. Внизу: Мир, Дела, Магазин, Духовный рост, Семья, Настройки.

Вкладка «Семья» теперь использует настоящий серверный семейный чат. Сообщения сохраняются в Supabase; существующий сервер ставит в очередь push-уведомления всем остальным членам семьи. Из уведомления о сообщении приложение открывает семейный чат.

Когда ребёнок открывает приложение, защищённая RPC-функция `report_child_app_open()` создаёт уведомление для родителей (один раз в 15 минут). В интерфейсе всем показано, что это событие отправляется родителям. Никакие тексты вопросов ребёнка к Миро и содержимое его экранов для этой функции не собираются.

Настройки: Firebase Push, тестовое уведомление для самого устройства, тихие системные звуки (вкл./выкл.), необязательная оригинальная синтезированная фоновая музыка (по умолчанию отключена), управление OTA-обновлениями, переход к отдельному духовному росту.

Android APK: `com.moymir.adventure`, versionCode 10, версия 2.8.0. Сборка подписана тестовым сертификатом debug и предназначена для семейного тестирования. Web-бандл совместим с базовой версией 2.7.0, OTA через Capgo. Новая native-библиотека не добавлена. Без доступа к Android-устройству доставку push и успешную смену bundle нельзя считать проверенной; проверены сборка, UI, SQL-триггеры и наличие Firebase-токенов. Для установки поверх тестовой 2.x Android подпись должна совпадать.

Оригинальное приложение 1.13.5 и все его данные сохранены. Не создавайте новую семью, войдите с прежними реквизитами.

## Новые функции «Мой Мир 2.9.0»

**Учёба:** родители вручную заполняют недельное школьное расписание по дням и урокам, добавляют домашние задания с датами сдачи. Илья видит школьные предметы и отмечает выполненное. Данные синхронизируются между семейными аккаунтами через Supabase; защищённые таблицы `moymir_school_lessons`, `moymir_school_homework`, `moymir_school_preferences`, RLS. Баллы и награды старой семьи не меняются.

**Напоминания:** родители задают и включают время напоминаний по трём независимым направлениям: ежедневные школьные уроки (названия предметов на каждый день), домашние задания (ежедневное напоминание проверить список) и стих на день. На телефоне ребёнка нужно разрешить Local Notifications; после первого запуска с интернетом недельное расписание запланировано локально и срабатывает даже без открытого приложения. Изменения родителей требуют открытия приложения ребёнком с интернетом для синхронизации расписания. При ограничениях Android возможны задержки.

**Ежедневный стих:** в разделе «Духовный рост» карточка текущей даты открывает официальный текст и комментарий на `https://wol.jw.org/ru/wol/h/r2/lp-u`, а Миро помогает обсудить прочитанное, не выдумывая его содержание. Отметка прочитанного в существующем духовном журнале сохранена.

**Миро:** кнопка возле домашнего задания открывает облачного помощника с заполненным вопросом. Запрос отправляет сам пользователь.

Проверено: `npm run build` и `npm run qa:family` с имитацией детского и родительского аккаунта, чтение и запись школьных заданий, настройка напоминаний, переход к Миро, связь семейного чата и прежний магазин. Реальная доставка уведомлений на аппаратном Android требует проверки пользователем.

## 2.9.3 · Ежедневные тексты 2026–2027 в приложении

В «Духовном росте» работает встроенная читалка, календарь дат 2026/2027, полный стих и комментарий, отметка «Прочитал» (+5 духовных очков за сегодня), обсуждение с Миро. Браузер и интернет для чтения **не нужны после первого сохранения текстов**.

Полные книги WATCHTOWER не публикуются через открытые релизы GitHub. Пользователь получил отдельный подготовленный архив из собственных EPUB в приватном чате. Родитель один раз выбирает его в разделе «Духовный рост → Добавить тексты из EPUB/ZIP», приложение сохраняет книги в private Supabase Storage bucket `moymir-daily-private` (RLS: родитель записывает, члены семьи читают), а Илья при первом подключении к интернету скачивает и хранит книги в IndexedDB своего телефона. Для офлайн-чтения при повторном запуске запоминается членство в семье из ранее авторизованного аккаунта; при выходе из аккаунта тексты другого семейного аккаунта не показываются.

Проверки `npm run qa:family`: вход под родительской и детской тестовыми ролями, импорт комбинированного архива и оригинального EPUB-формата на 365 записей, синхронизация двух сборников между аккаунтами, календарный выбор дня 2027 года, сохранение чтения при потере интернета, привычные награды и чат. Исходные EPUB проверены отдельно по календарю и имеют 365 ежедневных текстов каждый. **Проверка импорта на настоящем Android с реальными семейными учётными записями остаётся пользовательской.**

## 2.9.4 · За ежедневный текст теперь 10 духовных баллов

У Ильи нет экзамена или вопросов: чтение контролируется мягко по 60 секундам видимого текста, достижению конца комментария и минимум двум взаимодействиям. Время сохраняется между сеансами. После чтения открывается кнопка «Завершить чтение · +10». Баллы зачитывает `finish_daily_text_reading` на сервере, только за текущую дату в Europe/Madrid; повторное начисление невозможно. Старые 5 баллов за этот день при дочитывании превращаются в 10, а не суммируются. Старая кнопка ручной отметки для ежедневного текста заменена переходом к чтению.

Полный технический отчёт: `DAILY_READING_2.9.4.md`. Обычные задания, монеты, игровые миры, семейный чат, библиотека 2026/2027 и исходное приложение 1.13.5 не изменялись.

- **Сервер и безопасность:** база подсчитывает общие баллы по полной истории вместо усечения 1000 записей REST; исправлена проверка дат по `Europe/Madrid`, новые семейные таблицы защищены RLS. Фоновые запросы сокращены.

## 3.1.0 · Мой день, живой остров и семейная копилка времени

- **Мой день:** три режима по времени Испании (утро, после школы, вечер) на основе реальных семейных данных. После школы начинается после 14:30 в учебный день. Кнопка быстрого перехода размещена у 3D-острова, чтобы мир остался на первом экране.
- **Миро:** отвечает без сторонней нейросети на вопросы о реальном расписании, заданиях, рюкзаке, балансе и наградах, с приватным контекстом только текущего семейного аккаунта.

- **Семейный журнал:** родитель может проверить недавние подтверждения заданий, награды, духовные занятия и операции с игровым временем.
- **Офлайн-учёба:** ранее загруженные уроки, домашние задания и список рюкзака доступны при потере связи. Отметки и изменения требуют интернета.
