# Мой Мир 2.6 — оформление 2.4, прежний семейный прогресс

Новая сборка восстановлена из исходного кода 2.4.1 (коммит aaf67a4), а не из версии 2.5. Старое оформление, летающий Миро и два мира сохранены; в нижнем меню теперь 5 вкладок: Мир, Дела, Магазин, Духовный рост, Семья.

Подключение прогресса: войти с существующей учётной записью из основного приложения, не регистрировать новую семью. Через защищённый клиент Supabase программа читает существующие данные семьи: накопленный мир, текущий баланс, ежедневные и обычные задания, награды с прежними ценами, заявки и дисциплинарные списания, духовные достижения. Для начисления баллов, одобрения заданий, выдачи наград и духовных отметок используются штатные серверные RPC и защита семейных ролей. Данные в базе не мигрируются, не стираются и не дублируются.

Пока пользователь не вошёл в семейный аккаунт, игра не показывает выдуманные баллы или призы. Сама сцена доступна с нулевым стартовым видом. Раздел «Семья» остался локальной демонстрацией чата из версии 2.4 и явно обозначен как демонстрационный. Нативные push для отдельного Android-пакета ещё не подключены; основное приложение неизменно.

Миро: исходный бело-голубой робот, полноэкранный AI-чат. Сервер: moymir2-miro-ai, облачная модель gpt-oss:20b через LLM7, запасные внешние модели. Провайдеры могут ограничивать бесплатный доступ; ответы могут быть неточны. Детские личные данные не нужно отправлять внешнему API.
