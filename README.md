# МОЙ МИР 2.2 · отдельная экспериментальная игра

Новый интерфейс с независимыми персонажами: Тобик, Миро и Искорка. В Android по умолчанию используется отдельная интерактивная 2D-сцена из рендеров сторонних GLB-моделей. Трёхмерную сцену можно включить отдельно кнопкой «Проверить 3D». Это позволяет персонажам оставаться видимыми, когда WebGL в Android WebView не работает.

В режиме родителя можно создавать задания (ежедневные или разовые), проверять выполненное и принимать предложения Ильи. Ребёнок сам создавать задания не может. Миро отвечает текстом на основные вопросы в отдельном чате (правила, без подключения к нейросети). Прогресс сохраняется локально в приложении; совместной синхронизации пока нет.

## Локальный запуск
```bash
npm install
npm run dev
```

## Android
```bash
npm run build -- --mode android
npx cap sync android
cd android
./gradlew assembleDebug
```

Важно: роли «родитель/ребёнок» в этой тестовой версии переключаются без аутентификации. Она предназначена для испытаний и не предназначена для реального учёта баллов. Рабочее приложение «Мой Мир» 1.13.5 не затронуто.
