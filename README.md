# МОЙ МИР 2.1 — интерактивный остров

Отдельный экспериментальный прототип семейной игры, не связанный с действующей версией «Мой Мир».

**Запуск:**
```bash
npm install
npm run dev
```

Интерактивный 3D-мир использует Three.js и отдельные glTF-модели, которые загружаются из публичного хранилища. Прогресс демонстрационных заданий сохраняется локально в браузере. Нет авторизации, реальной семейной переписки и платёжных операций. Родительский режим в прототипе — демонстрационный.

Права на модели: собака — Quaternius (CC0), робот — Quaternius (CC0), белка — Simon Graff (CC BY 3.0), окружающие объекты — CreativeTrio (CC0) и Kenney (CC0). Подробности в CREDITS.md.
