# МОЙ МИР 2.4 — семейное приложение с ИИ-Миро

Изолированная тестовая версия. Основное приложение «Мой Мир» 1.13.5 и его база не изменены.

Сохранены оригинальные «Домик на поляне» и «Домик на дереве», 30 последовательных открытий в каждом мире, собачка, деревья и постройки. Открытия происходят после накопления очков за подтверждённые задания. Первый мир заканчивается при 1600 очках.

Возвращён оригинальный робот Миро. Нажатие открывает увеличенного робота и отдельный чат. Двойное нажатие или кнопка «Свернуть» возвращает на остров. Чат вызывает сервер Supabase Edge Function moymir2-miro-ai с доступом к облачной модели Pollinations openai-fast. Бесплатный внешний сервис может быть ограничен или прекратить работу. Тестовое ограничение: 50 запросов в день на IP-адрес. Не отправляйте в чат личные сведения ребёнка или документы.

В этом отдельном прототипе задания и баллы сохраняются локально, без синхронизации между телефонами. Родительский PIN локальный, не заменяет серверную авторизацию. Семейный чат демонстрационный. Ответы нейросети могут содержать ошибки.
