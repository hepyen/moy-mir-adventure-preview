# МОЙ МИР 2.7

Сохранено оформление версии 2.4: два последовательно открывающихся мира, исходный летающий робот Миро, отдельные вкладки, магазин, задания и духовный рост. После входа в существующий семейный аккаунт используются прежние данные Supabase, без миграции или обнуления.

**В версии 2.7 добавлено:**
- Переключаемые системные звуки кнопок, заданий, наград и переходов между мирами (Web Audio, громкость мягкая, звуки отключаются).
- Настоящие Android push: отдельное Firebase Android-приложение com.moymir.adventure зарегистрировано в прежнем Firebase-проекте. Для работы нажмите «Включить уведомления» после входа в семейный аккаунт. Токен регистрируется в старом защищённом семейном реестре. До фактической проверки доставки на телефоне push нельзя считать подтверждёнными.
- Центр уведомлений семьи с непрочитанными событиями.
- Ручная установка веб-обновлений через @capgo/capacitor-updater. Версии проверяются по публичному updates/latest.json, обновление скачивается как zip и переключается без переустановки APK. Обновление нативных компонентов всё ещё требует нового APK.
- Локальное уведомление о найденной новой версии, если разрешения Android уже предоставлены.
- Новая иконка: остров, домик, дерево, Миро и подпись «Мой Мир».

**Доступные данные** остаются серверными, не изменены. История баллов, наград, дисциплинарных мер и духовного развития отображается после входа под прежними аккаунтами. Функции требуют интернета.

**Ограничения:** устройство пользователя нужно проверить для FCM-доставки; тестовый семейный чат пока локальный, как и в 2.4; без установленного 2.7 OTA из более старого APK работать не будет. Бесплатная облачная нейросеть Миро может иметь непредсказуемые ограничения, вопросы отправляются внешнему провайдеру.
