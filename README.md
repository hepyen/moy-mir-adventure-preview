# Мой Мир 2.5 — семейная игра с ИИ-Миро

Это **отдельная Android-сборка** с сохранением исходного семейного сервера. Рабочее приложение «Мой Мир» 1.13.5 не изменяется.

После входа под **существующим** аккаунтом Supabase доступны те же данные: все задания, ежедневные дела, предложения ребёнка, награды и их точные цены, журнал покупок, дисциплинарные списания, духовный рост и продвижение миров. Все действия отправляются в существующую семейную базу. Ничего в базе автоматически не сбрасывается и не дублируется.

Игровая сцена: первоначальные «Домик на поляне» и «Домик на дереве», 30 этапов в каждом мире; 1600 очков на завершение первого. Миро — прежний бело-голубой робот, открывающий чат с настоящей онлайн-моделью. Серверная функция moymir2-miro-ai использует LLM7 (gpt-oss:20b, default) с резервным подключением к Pollinations. В тестах три последовательных запроса ответили успешно. Бесплатность и стабильность сторонних анонимных API не гарантированы; провайдеры могут включать ограничения. Текст вопросов передаётся внешнему API, не передавайте в них документы и личную информацию ребёнка. Ответы ИИ стоит проверять.

Верхнее меню содержит быстрые переходы: «Мои миры», «Ежедневные дела», «Предложить задание», «Все призы» и, для родителей, «Новое задание» и «Дисциплинарные меры».

**Примечание по уведомлениям:** в Android-пакете 2.5 включён просмотр уведомлений внутри приложения. Нативные push этого отдельного пакета ещё не настроены; в оригинальном приложении они продолжают работать.

## Локально

    npm run build
    npm run build -- --mode android
    npx cap sync android
    cd android && ./gradlew assembleDebug
