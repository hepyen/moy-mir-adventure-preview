# Мой Мир 3.0.0 Enhanced — большое обновление

Развивается **отдельная ветка** «Мой Мир 2/3». Оригинальное приложение 1.13.5, существующие семейные аккаунты, накопленные баллы, миры и призы не удалялись и не сбрасывались.

## Музыка

- Устранена причина гула: прежние четыре бесконечных синусоидальных генератора полностью удалены из музыкального движка.
- Написаны и сгенерированы **3 оригинальные мелодические композиции**: `meadow.mp3` (поляна), `treehouse.mp3` (домик на дереве) и `reading.mp3` (тихое чтение). Исходный код композиций: `scripts/create_original_music.py`. Никаких сторонних защищённых музыкальных файлов не использовано.
- В настройках появились выбор дорожки, режим автоматического переключения между разделами и громкость.
- Музыка останавливается при сворачивании приложения, приглушается во время беседы с Миро и начинает играть после пользовательского действия на Android. Включение/выключение и настройки сохраняются.

## Быстродействие и стабильность

- 3D-игровой движок загружается **по требованию**, а не на экранах школы, магазина и духовного чтения. Базовый JS-пакет сократился примерно с 1,64 МБ до ~0,7 МБ, 3D выделен в отдельный ресурс ~0,96 МБ.
- Исправлено создание новых и неосвобождаемых объектов RoundedBoxGeometry в 3D: геометрия повторно используется и освобождается при снятии объектов. Прорисовка 3D ограничена DPR=1,25, карта теней 512 px для экономии ресурсов.
- Семейный и школьный опросы сервера переведены с частых интервалов на 90 секунд, при сворачивании запросы приостанавливаются; добавлены события Realtime для оперативных обновлений семейных баллов (при поддержке Supabase).
- Сервер теперь считает баланс, очки и недельные показатели по **всей истории**, независимо от лимита 1000 строк REST-ответа. Обновлена корректность дат духовных занятий с учётом Europe/Madrid.

## Миро

- История сообщений разделена по идентификаторам семейных аккаунтов на одном устройстве. Старый общий ключ не используется.
- Встроены бесплатные локальные подсказки для поиска уроков, рюкзака, ежедневного стиха и правил начисления баллов. Такие запросы не требуют вызова внешней нейросети.
- Во время беседы музыка приглушается. Для сложных вопросов Миро продолжает использовать действующие онлайн-сервисы, которые иногда могут быть недоступны.

## Учёба

- Новый «**🎒 Мой рюкзак**»: список по следующему учебному дню, основанный на школьном расписании, заполненном вручную родителями.
- Родитель назначает конкретные вещи конкретным предметам; ребёнок ставит галочки, видит шкалу готовности. Отметки синхронизируются с семьёй, учитывают дату и сбрасываются на следующий учебный день. Нет выдуманных школьных принадлежностей.
- Новый родительский **недельный отчёт**: подтверждённые дела, выполненная домашняя работа, духовные баллы за семь дней.

## Родительское управление

- Награды теперь можно **изменять и приостанавливать**, сохраняя старые покупки и истории стоимости. У ребёнка отключённые призы не видны.
- Ежедневным заданиям можно менять название, значок, баллы, дни недели и активность.
- Все изменения доступны только родительской учётной записи и проверяются серверными функциями и политиками RLS.

## Новые занятия и остров

- В 3D-мире появились **ежедневные интерактивные мини-приключения**: помочь пёсику, белочке, Миро. После трёх найденных объектов ребёнок получает памятный значок в **семейном альбоме**. Значки не начисляют монеты и не обходят родительское подтверждение обычных дел.
- Родитель может создать в текущем списке дел семейное приключение: совместная прогулка, творчество, приготовление еды, помощь дома.
- «**Качество недели**» в духовном росте: ребёнок выбирает доброту, терпение, смелость или благодарность, ставит маленькую личную цель. Это **не экзамен**, штрафов и автоматически начисляемых духовных баллов за выбор нет.

## Проверки

- `npm run build` + регрессия `npm run qa:family` с двумя имитированными аккаунтами: школьные дела, списки рюкзака, редакторы заданий, библиотека 2026/2027, островные события, офлайн-подсказки Миро, загрузка всех трёх настоящих MP3, семейный чат на узком экране, защита духовных баллов.
- В тесте найден и исправлен реальный сбой плавного воспроизведения: WebView/Chromium иногда передавал в `HTMLMediaElement.volume` отрицательное число. Теперь громкость строго ограничена диапазоном 0..1.
- Проверены RLS и запрет вызова новых защищённых RPC без авторизации. Семейные записи не тронуты.
- **На физическом Android ещё нужно испытать** качество музыки на динамиках, реальную доставку уведомлений, плавность 3D после длительного использования. Автоматические тесты не доказывают это.

Новая версия распространяется через прежний механизм OTA; `nativeBaseVersion` остаётся `2.7.0`. Исходная установка Android заменять APK не требует.
