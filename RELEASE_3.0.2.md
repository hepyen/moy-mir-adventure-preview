# Мой Мир 3.0.2 — расписание Ильи на испанском

На основании предоставленного пользователем школьного расписания в закрытую семейную базу уже сохранены **30 уроков за неделю**, по 6 с понедельника по пятницу. Для каждого урока указаны испанское название, день, время начала и время окончания. Воскресенье и суббота не содержат занятий.

## В обновлении интерфейса

- Заголовок школьного расписания стал **Horario escolar**.
- Дни: **Lun, Mar, Mié, Jue, Vie**. По субботам и воскресеньям автоматически выбирается понедельник.
- Каждый день показывает шесть классов с точным временем. Большая перемена **Recreo · 12:00–12:30** отображается отдельной строкой, не считается уроком и не создаёт лишнего предмета для сбора рюкзака.
- Испанские названия из оригинального расписания сохранены, включая **Biología y Geología**, **Atención Educativa**, **Computación y Robótica**, **Geografía e Historia**.
- Автоматическое формирование списка предметов в «Мой рюкзак» использует эти сохранённые записи.
- Домашние задания, данные семьи, музыка, награды и настройки уведомлений не менялись.

## Проверка

- Серверная база: все 30 записей заполнены без перезаписи других таблиц.
- QA для двух семейных ролей: проверка испанских дней, шести уроков в понедельник, перемены и последнего занятия в пятницу; все предыдущие тесты пройдены.
- Обновление распространяется через OTA внутри уже установленного приложения; новых разрешений Android не требуется.
