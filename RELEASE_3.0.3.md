# Мой Мир 3.0.3 · Семь качеств, семь дней

Полностью переделана ранее неудобная функция «Качество недели» в «Духовном росте».

## Содержание

Ребёнок **сам** выбирает одно из **семи качеств**: доброта, терпение, честность, самообладание, благодарность, смелость, сочувствие. Ранее приложение автоматически показывало доброту как выбранное качество; теперь выбора по умолчанию нет. Родитель видит программу и прогресс, но не делает выбор за ребёнка.

Для каждого качества подготовлены **семь разных заданий**, всего **49 практических ситуаций**, привязанных к конкретным библейским стихам. Задания короткие, связаны со школой, домом, разговорами и помощью людям. Написаны специально для приложения и не являются буквальными цитатами из публикаций. В карточке качества указан источник из официальной библиотеки JW.ORG, в дневном задании — библейский стих для размышления. Браузер не требуется.

- Дни: понедельник — воскресенье, по часовому поясу `Europe/Madrid`.
- За **сегодняшнее** действительно выполненное задание Илья добровольно отмечает «Я выполнил задание» и получает **20 баллов исключительно духовного роста**. Не начисляются обычные монеты и очки игрового мира.
- Максимум 140 духовных баллов в неделю за эту программу. Нет штрафов за пропуск и нет проверочных вопросов.
- Завтрашние задания можно посмотреть заранее, но отметить нельзя. Пропущенные дни задним числом не оплачиваются.
- До первого выполненного задания качество можно изменить; после первой отметки выбор закреплён до начала новой недели. В следующий понедельник Илья может выбрать любое качество заново.
- Отметка о выполнении сохраняется на сервере в защищённой таблице, а баллы вносятся в `spiritual_activity_records` (шаг `growth-focus`). Итоги обновляются на общей шкале «Духовный рост». Одно начисление на ребёнка в календарный день, обработка повторного запроса идемпотентна.
- В базе применены RLS-политики: родитель читает прогресс семьи, ребёнок меняет только свою программу через проверяемые серверные RPC. Прямые клиентские INSERT/UPDATE отключены. Исторические духовные баллы, обычные задания и приложение 1.13.5 не изменялись.

## Публикации JW.ORG — основа методики

- «Будьте чуткими и заботливыми, как Иегова» (2018) — доброта и сочувствие.
- «Терпение» («Библейские стихи в помощь христианину») — терпение.
- «Нравственность» («Пробудитесь!», № 2, 2019) — честность.
- «Самообладание» («Пробудитесь!», № 2, 2019) — самообладание.
- «Научите детей выражать благодарность» («Помощь семье») — благодарность.
- «Проявлять мужество тебе по силам» («Наша христианская жизнь и служение», 2021) — смелость.

Оригинальные задания не копируют материалы JW.ORG. Библейские ссылки и точные названия источников сохранены, чтобы семья могла самостоятельно проверить мысль по публикациям и Писанию.

## Проверки

- `npm run build` и `npm run qa:family`: родительский и детский сценарии, исходное отсутствие выбора, переключение между всеми качествами, сохранение через RPC, семь дней, запрет отметить другой день, начисление 20 баллов, невозможность повторного начисления, закрепление выбранного качества, защита обычных монет и регрессии школьного расписания, чата, ежедневных стихов, музыки.
- Supabase: ограничения, права выполнения защищённых RPC, RLS и неизменность существующих записей проверены.
- Сборка Android и OTA подготовлена. Фактическое нажатие на смартфоне пользователя необходимо проверить отдельно.
