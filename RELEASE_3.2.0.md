# Мой Мир 3.2.0 — «Миро будит Илью»

## Готово
- Настоящий Android-будильник через AlarmManager.setAlarmClock с отдельным расписанием по дням недели.
- Нативные классы: планировщик, BroadсastReceiver, сервис воспроизведения и экран пробуждения, доступный с экрана блокировки при системном разрешении.
- Восстановление расписания после перезагрузки, изменения времени/часового пояса, замены APK и выдачи разрешения.
- Повтор через 5/10 минут, отключение повтора, кнопка «Я проснулся», возврат в приложение.
- Три оригинальные локальные мелодии, плавное нарастание громкости, вибрация и записанное русское приветствие Миро.
- Анимированный предпросмотр с исходным образом Миро в разделе «Настройки».
- Android разрешения: точные сигналы, уведомления и полноэкранный экран. В интерфейсе есть кнопки перехода в нужные системные настройки.
- Родитель управляет расписанием, ребёнок может просмотреть пробуждение без изменения времени.
- Тестовый запуск на устройстве через 4 секунды.
- Будильник хранится в локальных настройках Android, не влияет на монеты, задания, дневник и Supabase.

## Установка
Нативный модуль требует НОВОГО APK: OTA-обновление веб-ресурсов не добавляет Android-классы. Файл MOY_MIR_3.2.0_TEST.apk можно установить поверх 3.1.0; package id и подпись оставлены прежними. Перед проверкой разрешите «Будильники и напоминания», уведомления и полноэкранное отображение, затем сохраните время в разделе «Настройки» на телефоне Ильи.

## Проверки
- TypeScript + Vite build: PASS.
- Gradle assembleDebug: PASS (Android target 36).
- npm run qa:family: TOTAL_FAILS 0, включает проверку формы, мелодий, ролевых ограничений, анимированного предпросмотра, кнопок пробуждения для двух ролей и весь семейный регресс.
- Сертификат APK SHA-256 совпадает с версией 3.1.0: обновление поверх старой версии возможно без удаления её данных.
- **Не испытано на физическом Android**: точность срабатывания под Doze, экран поверх блокировки, реальная громкость и повтор после перезагрузки. Проверьте через кнопку «Тест на телефоне (4 с)».
- Полностью выключенный телефон не может гарантированно подать сигнал.
- Родительские настройки локальны для конкретного телефона, удалённой синхронизации расписания с другим телефоном в версии 3.2.0 нет.
