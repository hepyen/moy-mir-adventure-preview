# Мой мир 3.2.1 — исправление белого экрана

Исправлена ошибка Android 3.2.0: APK был собран с путями JS/CSS для GitHub Pages вместо встроенного Android WebView. После установки 3.2.0 показывался белый экран.

В APK 3.2.1 пути исправлены. Подпись приложения и идентификатор `com.moymir.adventure` сохранены, versionCode увеличен с 23 до 24. **Устанавливать поверх текущей версии; не удалять приложение и не очищать его данные.**

## Проверки
- Проверены фактические `assets/public/index.html` и все JS/CSS ссылки внутри APK: PASS.
- Мобильный Chromium открыл встроенную root-сборку, интерфейс 3.2.1 виден, ноль ошибок JavaScript и HTTP: PASS.
- Семейные автоматические тесты: PASS, `TOTAL_FAILS 0`.
- Android Gradle `assembleDebug`: PASS; подпись SHA-256 совпала с 3.2.0.
- **На физическом Android реальный запуск после установки не проверен.**

## Будильник Миро
Настройка в ⚙ Настройки → «Миро будит Илью». Требует разрешения Android на точные будильники. Через кнопку «Тест на телефоне (4 с)» проверить звук и экран блокировки.
