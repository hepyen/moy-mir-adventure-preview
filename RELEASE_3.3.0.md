# Мой мир 3.3.0: Миро будит Илью

**Тот же персонаж.** SVG-анимация в окне будильника теперь использует общий компонент MiroAvatar, извлечённый из исходного летающего робота World3D. На экране блокировки Android показан PNG, сгенерированный из того же SVG.

**Мелодия.** Новая авторская 13-секундная мелодия музыкальной шкатулки с восходящими колокольчиками (без сетевых ресурсов).

**Голос.** 30 офлайн-фрагментов с женским русским голосом: пробуждение, повтор обращения, уроки, зубы, кровать, рюкзак, названия основных школьных предметов. Android проигрывает их последовательно каждые несколько секунд и уменьшает громкость мелодии на время речи.

**Уроки.** Уже существующее школьное расписание синхронизируется в локальную память Android при открытии приложения. В установленной версии Миро перечисляет предметы текущего дня (набор уроков зависит от того, что введено в разделе «Учёба»). Неизвестные предметы не выдумываются: вместо названия звучит общее указание, а полное расписание показывается на экране. Необходима хотя бы одна синхронизация приложения, чтобы актуализировать офлайн-память телефона.

**Совместимость.** APK versionCode 25, versionName 3.3.0, подпись совпадает с APK 3.2.1. Установка поверх установленного приложения, без удаления или очистки данных.

### Выполненные проверки
- Android Gradle assembleDebug + статическая проверка WebView URL и всех ресурсов: PASS.
- Мобильная браузерная smoke-проверка: PASS, интерфейс 3.3.0 показан, нет JS-ошибок и запросов к отсутствующим файлам.
- Семейные регрессионные сценарии: TOTAL_FAILS 0.
- Подпись нового и старого APK совпала.
- Ресурсы голоса (30 клипов), 13-секундная мелодия и точный персонаж из мира встроены в пакет.

**Физический Android не подключён.** Звук при настоящем сигнале, разрешения, работу после перезапуска и экране блокировки нужно проверить на телефоне Ильи.

Для полноценной работы native будильника **требуется APK**, только OTA не устанавливает нативные изменения.
