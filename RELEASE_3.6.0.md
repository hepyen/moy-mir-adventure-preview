# Мой мир 3.6.0 — «Моё здоровье 2.0», этап 2 «Я расту!»

Это **OTA-обновление интерфейса**, оно устанавливается непосредственно внутри приложения («Настройки → Обновления → Обновить сейчас»). Переустанавливать APK НЕ нужно.

## Реализовано: 10 из 10 задач этапа
1. Вкладка «Я расту!» внутри «Моего здоровья», доступная Илье и родителям.
2. Самостоятельный ввод роста и веса Ильёй.
3. Дата каждого измерения с проверкой корректности.
4. Отдельный график роста.
5. Отдельный график веса.
6. История измерений по датам.
7. Исправление и удаление ошибочных записей.
8. Деликатное напоминание на экране примерно через 28 дней после предыдущего измерения, с возможностью отключить.
9. Родительский просмотр и редактирование семейной истории.
10. Сохранение локально и защищённая синхронизация между авторизованными родителями и ребёнком. Старый журнал доступен для явного переноса.

## Конфиденциальность и безопасность
- Серверная таблица public.moymir_health_measurements, RLS: только родитель семьи или сам ребёнок; анонимный доступ закрыт.
- Рост/вес не влияют на монеты и достижения; нет BMI, оценок тела, целевых килограммов или ограничений питания.
- Ранее сохранённые локальные измерения не удаляются: родитель может перенести их в семейный аккаунт по кнопке.
- Локальные записи без аккаунта остаются на устройстве, для межустройственной синхронизации необходим вход в семью.

## Проверки
- Android root build и статическая проверка WebView JS/CSS — PASS (для контроля совместимости, APK пользователю не требуется).
- Полная семейная QA: родитель/ребёнок, реестры измерений, импорт старого журнала, синтетическая межустройственная синхронизация, добавление, исправление, удаление, графики на 320px, дневная и ночная темы, сохранение привычек и прежние функции — TOTAL_FAILS 0.
- Supabase RLS включён, политики INSERT/SELECT/UPDATE/DELETE для authenticated установлены, посторонняя учётная запись не видит чужую историю.
- OTA zip имеет корневой index.html, версии 3.6.0, валидный SHA-256 и родную основу 3.3.0.

Физический Android пользователя и реальное OTA-обновление на нём недоступны для тестирования из этой сессии. Проверить работу самой кнопки на устройстве следует после публикации.
