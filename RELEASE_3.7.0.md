# Мой Мир 3.7.0 — день и ночь во всём приложении, игровая зарядка

**Обновление исключительно внутри приложения через «Настройки → Обновления → Обновить сейчас». Никакого APK скачивать не требуется.** Требуется установленная Android-основа 3.3.0 и выше, поддерживающая OTA.

## Исправление общего оформления

Режим «День / Ночь / Авто» отныне управляет всем приложением, а не только «Моим здоровьем». Переключатель находится в общих настройках и в здоровье, выбор единый. Автоматический режим следует теме Android. Настройки сохраняются через перезапуск.

Все основные экраны: главная, 3D-поляна, домик на дереве, дела, школа, магазин, духовный рост, семья и чат, настройки, здоровье. 3D-сцена динамически изменяет цвет неба и освещение. Исходные персонажи и игровые достижения сохранены. Учитывается prefers-reduced-motion.

## Этап 3. Интерактивная зарядка с Миро (9 задач)

1. Игровая анимированная площадка с красивым садом.
2. Оригинальный Миро из мира с домиком машет руками; дополнительная схематичная фигура наглядно показывает движение.
3. Семь щадящих упражнений без прыжков.
4. Запускаемый таймер 7 минут, автоматическая смена движений; пауза останавливает отсчёт.
5. Кнопки «Начать», «Пауза», «Пропустить».
6. Авторская 19-секундная музыкальная петля в MP3, отключаемая.
7. Русские голосовые инструкции Миро для каждого упражнения, оригинальные локальные MP3; все работают без интернета.
8. Финальная поздравительная анимация со звёздами.
9. Облегчённый вариант около 4 минут, остановка при боли, кнопка отдыха. Пропуск всех шагов не выдаёт ложную отметку о зарядке.

## Проверки

- Полные Playwright семейные тесты parent + child — TOTAL_FAILS 0. В том числе переключение темы во всех разделах, сохранение после перезапуска, музыка и голос, реальное движение рук общего Миро, игровая анимация, семиминутный отсчёт, пауза, облегчённый режим, пропуск, завершение и отмена ложной отметки.
- Android WebView root smoke — PASS (исключён белый экран и отсутствующие ассеты).
- Android Gradle assembly — PASS (внутренняя проверка, APK не публикуется для этой версии).
- Архив OTA: index.html, CSS и JS, 11 MP3 со всеми голосовыми подсказками, целостность и SHA-256 — PASS.
- Физический запуск после OTA на телефоне пользователя необходимо проверить отдельно.
