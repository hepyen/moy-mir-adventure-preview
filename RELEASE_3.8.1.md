# Мой мир 3.8.1 — восстановление доступа ребёнку

## Что добавлено
В родительских настройках появилась секция «🔐 Восстановить доступ ребёнку». Если ребёнок забыл пароль, родитель может задать ему новый, подтвердив действие паролем собственного аккаунта. На экране входа ребёнка есть подсказка.

## Защита
Серверная функция Supabase `moymir-parent-child-access` проверяет действительный сеанс родителя, его роль в `family_members`, принадлежность ребёнка той же семье и текущий пароль родителя. Только после этих проверок новый пароль сохраняется через Supabase Auth. Сервисный ключ не передаётся приложению.

Изменяется лишь пароль для входа. Учётная запись, семейные задания, баллы, достижения, награды, чат и миры остаются прежними. Требуется интернет. Смена пароля не удаляет существующие сохранённые сеансы на других телефонах.

## Обновление
Это OTA-обновление пользовательского интерфейса для установленной Android-основы 3.3.0 и новее. APK не требуется. Откройте ⚙️ Настройки → Обновления → Проверить → Обновить сейчас.

## Контроль
Сборка TypeScript/Vite, семейные сценарии родителя и ребёнка, проверка Android WebView и архив OTA. Полное восстановление с настоящим паролем родителя должно быть подтверждено самим владельцем аккаунта на устройстве.

Серверный исходник развернут в Supabase Edge Functions (проект moy-mir); для обслуживания получать текущую версию функцией просмотра Edge Function из Supabase, не развёртывать локальные заглушки.
