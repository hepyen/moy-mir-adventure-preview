# Мой мир 3.8.10 — честные тесты по географии

- Сервер формирует новую перестановку A, B, C для каждого из 25 вопросов и при каждом новом тесте; нет повторяющейся последовательности.
- Правильность проверяет Supabase на основании неизменяемой серверной перестановки, а не фиксированной буквы.
- Родительский отчёт показывает действительный выбранный вариант с учётом порядка именно той попытки.
- Старые результаты сохранены для учебного разбора, аннулированные баллы больше не считаются. За первый одобренный тест «La atmósfera y el tiempo» оставлено 50 баллов; прочие прежние награды сняты.
- Награды на экране берутся напрямую из семейной базы и учитывают её актуальный баланс.
- Новые тесты требуют версии 3.8.10; старые версии не могут начислить баллы за предсказуемую последовательность.
- Сохранены все прежние функции, четыре раздела географии, 100 вопросов, 50 иллюстраций и выбор времени.

Проверено: серверная генерация перемешивания и подсчёт ответов, защита от старых клиентов, сборка Android, тесты экранов родителя и ребёнка.
