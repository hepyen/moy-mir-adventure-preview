# Мой мир 3.8.4 · Аварийное восстановление экрана

Исправлен критический дефект OTA версии 3.8.3: адреса JavaScript и CSS были собраны с префиксом GitHub Pages вместо локального корня Android WebView. Это вызывало белый экран после обновления. OTA 3.8.4 собирается строго в режиме Android, а отдельный автоматический тест проверяет расположение файлов, путей JS/CSS и музыкальных файлов внутри ZIP.

Сохраняются все улучшения 3.8.3: Илья может сам настраивать время, дни недели, включение сигнала, мелодию, вибрацию и голос в детском профиле. Прогресс, баллы, накопления и семейные роли не затрагивались.

Если после неисправной версии приложение не запускается, не удаляйте его и не очищайте данные. Сначала принудительно остановите и снова откройте программу: Capgo должен откатить повреждённый пакет на работавшую ранее версию. После восстановления установите 3.8.4 через настройки приложения.
