# «Мой мир» 4.0.0: Английский с Миро

**Дата:** 19 ноября 2026 года. Вкладка **Учёба → Английский с Миро**.

## Для ребёнка

- Диагностика английского: 18 заданий, оценка начальных знаний, анализ ошибок без штрафов и без начисления баллов за тест уровня.
- Восемь уроков по 6 вопросов: am/is/are, have got/has got, Present Simple, Present Continuous, there is/are, Past Simple, школьный словарь, вопросы.
- В каждом уроке объяснение по-русски, примеры на английском с озвучиванием, вопросы с переменным расположением вариантов, итоговый разбор ответов и рекомендации для повторения.
- Диалоги с ИИ через существующий бесплатный сервис Миро. Устные ответы при наличии Web Speech API; при его отсутствии остаётся клавиатура. Внешний ИИ может быть временно недоступен или иметь квоты; обычные уроки не зависят от его ответа.
- Промежуточные ответы урока сохраняются локально для восстановления после перехода на другую вкладку.

## Баллы: точное правило

- За **один завершённый 15-минутный учебный сеанс с шестью ответами начисляются 30 баллов** независимо от количества ошибок.
- 15 минут подтверждаются временем сервера (Europe/Madrid), а не таймером телефона.
- Начисление не повторяется за один и тот же урок в один календарный день. Разные темы можно изучать отдельно; каждая полноценная тема получает свои 30 баллов.
- Нельзя записать себе баллы с устройства: клиент имеет только чтение сеансов; начало и завершение проводятся через серверные RPC, а выбор ответов сверяется с приватным банком.
- Для соблюдения целостности существующего `point_ledger` награды за английский хранятся в `moymir_english_sessions.points_awarded` и учитываются в `moymir_family_overview` наряду с наградами за географию.

## Для родителя

- История пройденных тем, оценки, начисления, рекомендации для повторения и исходная диагностика. Переписка ребёнка с внешним ИИ в родительском отчёте не сохраняется.

## Безопасность, совместимость и QA

- Таблица `moymir_english_sessions` с включённой RLS; только семейное чтение, никакой клиентской записи. Приватный банк ответов в `moymir_private` не читается клиентом. Без входа нельзя выполнять функции начала или завершения.
- Серверное транзакционное испытание с откатом подтвердило: раннее завершение отклонено, полные 15 минут при ответах дают +30, повтор темы +0, диагностика +0; данные реального ребёнка после испытания неизменны.
- 435 общих автоматических проверок без ошибок; 25 проверок репетитора в мобильной эмуляции без ошибок; 24 проверки банка заданий без ошибок.
- Android versionCode 63, versionName 4.0.0. OTA заменяет только веб-код; для этого обновления не требуется переустановка APK.
- Android Gradle сборка, корректность ссылок WebView и цифровая подпись подтверждены. На настоящем телефоне Ильи новая версия ещё не проверена.
