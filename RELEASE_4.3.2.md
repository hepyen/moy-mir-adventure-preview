# «Мой мир» 4.3.2 — подарок PlayStation один раз в день и накопление игрового времени

## Правило подарка

- Награда «30 минут PlayStation» из действующего семейного магазина стоит **60 монет** (цена не изменена). Каждый ребёнок может отправить **не более одной заявки за календарный день**, включая отклонённые заявки, по часовой зоне Europe/Madrid.
- Если за сегодня уже есть заявка, кнопка показывает предупреждение «Илья, ты уже активировал подарок сегодня». **Повторная заявка не отправляется родителю**. Повторный прямой серверный вызов тоже отклоняется. Завтра можно снова оформить подарок.
- Если вчерашний запрос всё ещё ожидает родителя, он не блокирует сегодняшнюю покупку при наличии монет.
- Родитель по-прежнему самостоятельно одобряет или отклоняет каждый заказ. Отклонённый подарок не списывает монеты и не добавляет игровое время.

## Копилка

- **Одобрение** этой магазинной награды атомарно зачисляет **+30 минут в `moymir_playtime_credits`**. Каждое одобрение связано с исходным ID заказа. Повторное подтверждение не может создать второе зачисление: уникальный индекс `source_reward_request`.
- Одобренные минуты **не сгорают в полночь и накапливаются без ограничения сверху**. В копилке дополнительно показываются часы и минуты, например 90 минут = 1 ч 30 мин.
- Дневной лимит фактической игры не изменён. Родитель задаёт его отдельно. Копилка показывает право на игровое время; приложение напоминает о конце сеанса, но не выключает приставку аппаратно.

## Миграция данных и безопасность

- Исторические записи до **19 ноября 2026 года** оставлены нетронутыми: раньше могли быть несколько заказов за один день. Новая серверная уникальность применяется с начала 19.11.2026 по времени Мадрида. Старые одобренные заказы не зачислялись задним числом, поскольку часть времени могла быть уже использована.
- Сервер проверяет роль ребёнка при покупке и роль родителя при одобрении. RLS действует на таблицы запросов; прямое редактирование заказов или зачисление минут из аккаунта ребёнка запрещено.
- Конкурентные запросы сериализуются advisory lock, уникальный индекс защищает от гонок между устройствами.
- Серверные тесты проводились с последующим ROLLBACK: одна покупка сегодня / повтор отклонён; одобрение добавляет ровно 30 мин; повторное подтверждение не дублирует; отклонение не начисляет; две покупки за разные дни дают 60 накопленных минут без изменения дневного лимита.
