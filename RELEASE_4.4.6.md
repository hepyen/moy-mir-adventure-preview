# Мой мир 4.4.6 — Игровые приключения
Шесть сюжетных миссий, 18 коллекционных материалов и шесть рецептов для мастерской, по две миссии на каждый из трёх миров. Находки появляются непосредственно в открытых 3D-мирах по мере достижения прежних порогов очков. Камера может приблизиться к месту по подсказке; есть альтернативная кнопка подбора. Собранные материалы попадают в рюкзак, расходуются при создании предмета, а готовый предмет остаётся в коллекции и отображается в мире. Повторная выдача материалов и повторное создание исключены. Игровые материалы не меняют монеты, духовные баллы, очки развития или реальные награды. Родительский интерфейс только для просмотра локальных данных. Прогресс пока хранится на устройстве, облачная синхронизация не реализована. 24 мобильные проверки с тестовыми аккаунтами пройдены, APK на физическом телефоне и непосредственный выбор предметов касанием 3D-сцены не проверялись.
