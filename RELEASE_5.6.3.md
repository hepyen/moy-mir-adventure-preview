# Мой мир 5.6.3 — Тестовый семейный пульт Samsung
В разделе Награды → Игровое время родитель может открыть тестовый пульт Samsung F-серии. Новый нативный модуль Android 4.4.4 работает в домашней сети по явно указанному приватному IPv4 на TCP 55000; сопряжение требует разрешения телевизора. Доступны проверка подключения, меню источников и команда выключения с подтверждением на телефоне. Сетевые команды не отправляются при отказе телевизора. IP хранится локально. Модуль не меняет прошивку телевизора, не гарантирует выключение, не блокирует повторное включение и не является защищённым системным родительским контролем. Автоматическое отключение по таймеру не реализовано. Java-тест с имитацией телевизора, проверка типов, сборка APK, подпись и локальные ресурсы проверены. Физический телевизор не найден при SSDP-поиске Samsung; реальные команды не проверены. APK необходим для новых нативных функций; старый APK сохранён.
