# Кто хочет стать пионером? TV — 1.1.0

- TCL Android TV 11 (совместимо с Android API 24+), приложение com.moymir.pioneerquiz.tv.
- 30-секундный таймер на каждый вопрос с тиканьем и автоматическим завершением раунда.
- Спокойная фоновая музыка и дополнительные звуки ответов, подсказок и победы.
- Экран викторины 16:9 без прокрутки, проверены 1920×1080, 1280×720 и 960×540.
- Подтверждение выхода из игры и подтверждение трёх подсказок, управление D-pad.
- Золотая звезда и раскрытая Библия — иконка приложения и новый баннер.
- Прогресс локально сохраняется при обновлении приложения поверх версии 1.0.0.
- Проверены: таймер, неверный ответ при нуле, подтверждение подсказок, кнопка выхода и навигация пультом.
- Физическое устройство TCL не подключено для аппаратной проверки.
