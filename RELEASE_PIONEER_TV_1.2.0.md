# Кто хочет стать пионером? TV 1.2.0

- Теперь на одном телевизоре могут играть разные участники. Имя нового игрока вводится вручную.
- Сохранённые имена доступны для выбора при каждом новом запуске.
- У каждого игрока собственные вопросы, прохождения, достижения, таймер и баллы.
- Добавлена таблица лидеров с сортировкой по заработанным очкам, количеством побед и числом игр.
- Предусмотрено однократное присвоение результатов прежней версии выбранному игроку.
- Сохранены музыка, 30-секундный таймер, управление пультом, подтверждение выхода и подсказок.
- 300 вопросов работают локально и без интернета.
- Проверено 5 профилей, рейтинг, переключение профилей, перенос предыдущего прогресса без дублирования и сохранность после перезапуска.
- Android TV APK подписан прежним сертификатом и ставится поверх предыдущей версии; физический TCL пока не проверен.

Важно: без авторизации профили можно выбрать всем, кто пользуется телевизором. Баллы хранятся на этом устройстве, синхронизации между телевизорами нет.
