# Мой мир 3.8.6 — исправлен подтверждённый вылет Firebase

Диагноз подтверждён Android logcat подключённого телефона: FATAL EXCEPTION CapacitorPlugins в PushNotificationsPlugin.register: Default FirebaseApp is not initialized.

В Android APK отсутствовал google-services.json для фактического пакета com.moymir.adventure. Единственный найденный оригинальный google-services.json относится к com.moymir.family и не может использоваться без регистрации нового Firebase Android-приложения.

В версии 3.8.6 блокируется ошибочная регистрация FCM и выводится ясное сообщение о временной недоступности push. Остальные локальные функции, будильник Миро, локальные уведомления и работа с семейной базой сохраняются. Отдельный серверный / OTA пакет для этой неисправности не требуется: нужен исправленный APK, обновляемый поверх прежней установки с той же подписью без удаления данных.

После подключения правильной Firebase-конфигурации системные push нужно включить в отдельной проверенной сборке. Запуск 3.8.6 должен быть проверен на телефоне через ADB до публикации.
