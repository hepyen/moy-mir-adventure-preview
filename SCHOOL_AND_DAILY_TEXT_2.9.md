# «Мой Мир 2.9» — школа, задания, ежедневный стих

Новое в отдельном приложении; прежние баллы, награды, семья, 2 мира и старый Миро сохранены.

## Учёба

- Раздел «📚 Учёба» с выбором каждого дня недели. Родитель вручную вводит реальные предметы, номер урока, необязательное время и примечание. Никакие предметы предварительно не придуманы.
- Родитель записывает домашнее задание: предмет, подробности, срок сдачи. Вход с существующим семейным аккаунтом позволяет видеть одни и те же данные на устройствах ребёнка и родителя.
- Илья видит ближайшие задания и может отметить выполнение; старые записи не исчезают, выполненные доступны в истории.
- «🤖 Миро»: открывает существующую настоящую нейросеть с подготовленным вопросом, но ребёнок сам нажимает «Отправить». Ответы нужно проверять.

## Напоминания

- Родитель в разделе «Учёба» отдельно задаёт время для утренних уроков, вечерних домашних заданий и ежедневного стиха. Все три переключателя **по умолчанию выключены**.
- На телефоне ребёнка необходимо разрешить уведомления. После синхронизации приложение планирует локальные Android-напоминания по будням с действительными предметами, ежедневное напоминание проверить домашние задания и ежедневное духовное напоминание.
- Расписание сохраняется в защищённых семейных таблицах Supabase с RLS. Никаких старых заданий или баллов базы не меняет.
- Если родитель меняет расписание, Илья должен открыть приложение с интернетом, чтобы телефон обновил свои запланированные уведомления. При отключённых уведомлениях или ограничениях энергосбережения Android доставка может задерживаться.

## Ежедневный текст

Карточка «📖 Текст на сегодня» в отдельной вкладке «Духовный рост» открывает официальный ресурс https://wol.jw.org/ru/wol/h/r2/lp-u с актуальным текстом и комментарием. Это содержание официального сайта, а не неавторизованная копия или выдумка нейросети. Отметка «Прочитать ежедневный стих» и духовные очки остаются прежними.

## Проверка

`npm run build`, `npm run qa:family`; тестовые семейные роли, чтение и запись учебного расписания, создание и отметка домашнего задания, настройка времени, связь школьной вкладки с Миро, ежедневный стих, прежний семейный чат.

Аппаратное срабатывание Android LocalNotifications на конкретном телефоне проверяется после установки и разрешения уведомлений; без устройства утверждать полную доставку нельзя.

2.9 — обновление веб-части через существующий Capgo OTA. Для ранее установленной 2.7+ новая установка APK обычно не нужна.
