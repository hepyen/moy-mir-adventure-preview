ВОССТАНОВЛЕНИЕ ПРИЛОЖЕНИЯ «МОЙ МИР»
------------------------------------
Версия: 3.8.4 RECOVERY, native versionCode 50
Package: com.moymir.adventure

1. Не удаляйте установленное приложение.
2. Скачайте MOY_MIR_3.8.4_RECOVERY.apk на тот же Android-телефон.
3. Откройте файл и согласитесь на ОБНОВЛЕНИЕ существующего приложения.
4. При запросе Android разрешите установку этого файла из выбранного источника.
5. После установки откройте «Мой Мир». Не выбирайте «Очистить данные».

APK собран с тем же сертификатом, что оригинал версии 3.3.0.
Новая нативная версия сбрасывает повреждённый OTA-бандл при обновлении.
Данные профиля и семейная база не меняются. Гарантию состояния
данных конкретного телефона без проверки устройства дать нельзя.
